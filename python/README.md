# Biblioteca para Maratonas de Programação

Este pacote contém exemplos em Markdown para documentação de algoritmos comuns em maratonas de programação.

## Arquivos incluídos

- `busca_binaria.md`
- `dfs.md`
- `bfs.md`

## Estrutura sugerida para cada algoritmo

```md
# Nome do algoritmo

## 📚 Introdução

Explicação simples sobre o que é o algoritmo e quando usar.

## 🤔 Como funciona

Descrição passo a passo da ideia principal.

## 🤓 Implementação

Código em Python.

## ⚠️ Observações

Complexidade, limitações e cuidados importantes.
```
